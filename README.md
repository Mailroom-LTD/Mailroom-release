# Mailroom — Releases

Signed release artifacts for **Mailroom**, the privacy-first email cleanup app.

- Website: https://www.mailroomclean.com
- Downloads: see the **Releases** tab.

Windows builds are Authenticode-signed; Linux packages (`.deb` + AppImage) are GPG-signed
(public key published at mailroomclean.com). Every release is independently scanned on
VirusTotal, with the report linked from each release's notes.
